Proyecto Integrador Final

Dermopiel fue desarrollado como proyecto final de la Semana 16. El sistema administrativo utiliza Flask, autenticación de usuarios, gestión de sesiones y una base de datos relacional.

GitHub Pages presenta la parte informativa del proyecto. Las funciones de Flask y la base de datos se ejecutan en el servidor.
