# PROYECTO FINAL – DERMOPIEL

## Desarrollo de Aplicaciones Web – Semana 16

Dermopiel es un sistema web desarrollado para gestionar la información de un centro de servicios estéticos.

### Tecnologías utilizadas
- Python y Flask.
- HTML y CSS.
- MySQL.
- GitHub.

### Funcionalidades
- Login y autenticación de usuarios.
- CRUD completo de Clientes.
- CRUD completo de Servicios.
- CRUD completo de Facturación.
- Gestión de Empleados.
- Base de datos con tablas relacionadas.
